# 学术社会地图 · 项目总结

> 2026-08-21 一次性梳理 + 全面修复后的项目快照（33 个测试全过、流水线 e2e 跑通、S2 默认不再用）。

---

## 一句话定位

> 输入一段研究 idea 文本 → 系统自动"调查"它所处的学术社区 → 输出一张可交互的研究者网络图 + 一份结构化行动报告。

**核心设计**：图里的边（谁引用谁、谁合著）来自 OpenAlex / Semantic Scholar **真实数据**，不是 LLM 编造；LLM 只负责抽取方法/概念和生成检索 query。

---

## 技术栈

- **后端**：Python 3.13 + FastAPI + uvicorn
- **数据源**：OpenAlex（默认）+ Semantic Scholar（备选）
- **LLM**：DeepSeek（主）+ MiniMax（备），OpenAI 兼容协议
- **图**：NetworkX（图构建与排序）+ pyvis（交互式 HTML）
- **测试**：pytest + httpx（33 用例，离线）

---

## 六步流水线

```
① LLM 理解 idea ─→ ② 检索种子论文 ─→ ③ 1 跳引用扩展 ─→ ④ 方法抽取 ─→ ⑤ 推理分析 ─→ ⑥ 输出
```

| 步 | 做什么 | 文件 | 关键算法 |
|---|---|---|---|
| ① | 抽方法/概念 + 生成 3 条 query | `extractor.py` | LLM JSON 结构化 + 长度容错解析 |
| ② | 检索 + 标题优先排序取 Top-10 | `main.py` | 标题命中优先，词项重合度次之 |
| ③ | 1 跳引用扩展 + 合著者 | `graph_builder.py` | 4 线程并发，top-25/seed 剪枝 |
| ④ | 高被引论文摘要 → 方法名（≤3/篇） | `extractor.py` | 多论文分批并发 |
| ⑤ | 核心人物/引用网/方法谱系/查漏 | `reasoning.py` | 两级排序 + 代表作去重 + token 集匹配 |
| ⑥ | Markdown 报告 + HTML 图谱 | `report.py` + `visualize.py` | 6 章 + 力导向布局 |

## 双数据源切换

| 数据源 | 默认 | 限速 | Key | 备注 |
|---|---|---|---|---|
| OpenAlex | ✅ | 1000/天（key 可大幅提升）| 可选 | 日常推荐：免费、字段无坑、比 S2 快约 4 倍 |
| Semantic Scholar | ❌ | ~1 RPS（需 key）| 推荐配置 | S2 接口"经常报错"——本轮起默认不再用，仅作备选 |

**切换入口**（三处独立、互不影响）：
- CLI：`main.py --data_source {openalex,s2}`
- Web UI：下拉框（默认 OpenAlex）
- API：`POST /api/run` 的 `data_source` 字段

**架构关键**：交互端点用 `datasource.get_module(name)` 按名取模块，**不写全局**——避免和正在跑的流水线线程抢 `_BACKEND`。流水线仍每次 run 开头 `set_backend` 一次，切换能力完整保留。

## 安全与配置

| 项 | 实现 |
|---|---|
| API key 存储 | keyring（Win Credential Manager / Mac Keychain / Linux SS）→ 文件回退 → 全程兼容旧明文 |
| API key 读取优先级 | 环境变量 → keyring → 文件 |
| 路径穿越防护 | `_safe_segment` 拒绝 `.` `..`；`run_file` 加父目录校验 |
| 并发 run | `/api/run` 检测到已有任务返回 409（与 delete-while-running 同款） |
| idea 隐私 | `POST /api/run` 用 JSON body，idea 不再出现在 URL / 浏览器历史 / 服务器 access 日志 |
| 输入校验 | Pydantic `Field(ge/le)` 自动拦截越界参数 → 422 |
| DeepSeek key 缺失 | `import config` 不再崩溃，调用时才报友好错误 |

## 已知限制与遗留

### 业务层面
1. **方法关系是唯一非"社会事实"部分**——LLM 从摘要抽取论文→方法边，会错。带置信度、人工确认后才视为事实。
2. **实体消歧**——同名作者（如 "J. Wang"）。靠数据源自带的作者 ID 缓解。
3. **1 跳以上扩展噪声陡增**——层数限制 1 跳 + 语义相关度剪枝。
4. **覆盖盲区**——仅英文文献；OpenAlex/S2 对非英语/灰色文献覆盖有限。

### 操作层面
- 历史 run 的 `graph.html` 仍是旧样式（需要重跑才会更新工具栏/图例）

### V2 方向（未实现）
- 机构网络、概念层级、社区检测（学派）、Neo4j 存储
